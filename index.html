Indoor navigation for All Map editor

ยินดีต้อนรับสู่ระบบสตูดิโอจัดแต่งแผนที่นำทางอาคารอัจฉริยะ (Multi-Floor BLE Beacon Map Editor)
กรุณาเลือกวิธีการเริ่มต้นใช้งานเพื่อเข้าสู่แผงควบคุมหลัก

กำหนดชั้นสำหรับแผนที่ใหม่

ระบุชั้นทั้งหมดที่คุณต้องการจัดทำระบบนำทาง

💡 ตัวอย่าง: ระบุ 1, 2 สำหรับอาคาร 2 ชั้น หรือ 1, 2, 3 สำหรับอาคาร 3 ชั้นตามลำดับ
💡 คำแนะนำเพิ่มเติม:
หลังจากเลือกสร้างแผนที่ใหม่ คุณสามารถอัปโหลดรูปภาพพื้นหลังของแต่ละชั้น (ชั้น 1, 2, 3) เพื่อระบุโหนดนำทางและเชื่อมต่อบลูทูธตั้งค่า ESP32 ไร้สายได้ทันที

เพิ่มโหนดใหม่

แก้ไขข้อมูลโหนด

อัปโหลดรูปภาพแผนที่แยกชั้น

คุณสามารถอัปโหลดภาพแผนที่ (PNG/JPG) ของแต่ละชั้นได้ ข้อมูลภาพจะถูกแปลงเป็น Base64 และแนบถาวรไปกับไฟล์ส่งออก

ตั้งค่า ESP32 ไร้สาย (OTA)


สแกนและแก้ไขข้อมูลบอร์ด ESP32 ด้วยสัญญาณบลูทูธเบราว์เซอร์
เชื่อมต่อ ESP32 สำเร็จ!
